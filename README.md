# Pic Sort Tool
Tool for sorting pictures into directories.
Good for sorting your holiday pictures.

## Features
* Preview images
* Move with space into target directory

## Keys

Key          | Function
-------------|---------
Arrows       | Next/previous image/video
Page up/down | Skip 10 images/video
Home/end     | Go to first/last image/video
R            | Rotate
M            | Mirror
Space        | Move picture/video to destination folder
